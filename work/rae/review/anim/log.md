## RAE 덱

- codex는 3·4장을 두 애니메이션으로 대체, agy는 3장(관련 연구)은 두고 4장만 한 장으로 대체를 권했다.
- **결정: 3장은 둔다**(관련 연구는 애니메이션이 대신 못 함 — agy). **4장(두 통념, 글만 있는 가장 얇은
  장)을 애니메이션 A로 바꾸고, 애니메이션 B를 그 뒤에 추가**한다. 사용자가 1–3장을 원했고, 두 장은
  서로 다른 것을 보여 준다: A는 latent가 어떻게 바뀌는지(Fig. 2를 다시 그림), B는 RAE 위에서 복원과
  생성이 어디서 갈라지고 네 가지 변경이 어디에 붙는지(덱의 나머지 지도). 22장이 되므로 다른 장의 시간을
  줄여 1200초를 지킨다. 상호작용 4장(A, B, 사다리 stepper, 그림 탭) = ⌊22×0.2⌋.
- agy의 1장 안(4 beat에 두 내용을 합침)은 한 장에 사건이 너무 많다: 압축 → 팽창 → 세 병목 → head.
- 두 장 모두 gFID·rFID 수치를 넣지 않는다(agy: "어디서"와 "얼마나"를 분리, 사다리는 14장). Fig. 2의
  GFLOPs와 토큰 크기만 쓴다.
- A의 SD-VAE 토큰(256개 × 16차원)은 `(32/2)² = 256`, `2×2×4 = 16`으로 계산한 값(derived, Sec. 6.2 / Table 10의
  patch 2). RAE는 patch 1, 256개 × 768차원(Sec. 3, Sec. 4).
- B의 위치 근거: 폭 — Sec. 1 (1), Sec. 4.1, Theorem 1; schedule shift — Sec. 1 (2), Sec. 4.2(유효 차원 = 토큰 수 × 차원);
  노이즈 증강 — Sec. 1 (3), Sec. 4.3(디코더 학습 때 n ∼ N(0, σ²I)); DDT head — Sec. 5, Fig. 5($z_t = M(x_t)$,
  $v_t = H(x_t \mid z_t, t)$).

## codex 코드 검토 (`codex_review.md`) — 처리

| # | 처리 | 결정 |
|---|---|---|
| 1 번들이 head에 인라인해 초기화 실패 | 기각 | `bundle_html.py`는 `<script src … defer>`를 지우고 `</body>` 앞에 문서 순서대로 넣는다. 번들 파일 QA(1920·1024)와 클리커 재생 시험이 통과했다 |
| 2 render가 던지면 재생이 멈춘 채 남음 | 수용 | 모든 render 호출을 `draw()`로 감싸고, 실패하면 `disable()`: 재생 취소, 원본 SVG 복원, 단계 제거, 모든 beat 글 표시 |
| 3 개요에서 화살표가 썸네일을 첫 그림으로 | 수용 | 개요가 열린 동안 `go()`는 애니메이션을 마지막 beat로 둔다 |
| 4 스크립트가 없거나 define이 주석뿐 | 수용 | `load` 때 묶이지 않은 블록은 `disable()`(콘솔 오류), QA는 `data-beats`와 실제 beats 수를 대조 |
| 5 beats가 문자열이면 NaN으로 rAF가 계속 | 수용 | 유한한 숫자·증가·`render` 함수 검사 |
| 6 OS reduced-motion + `?motion=0`에서 M | 수용 | M은 현재 적용 상태를 명시적으로 뒤집음(`no-motion`/`force-motion`), 키 반복 무시 |
| 7 `#/n/99` | 수용 | 단계를 `0..data-steps`로 제한(stepper도 같이) |
| 8 토글: 숫자 키 뒤 방향키가 이전 버튼 기준 | 수용 | 그룹 안에 포커스가 있으면 숫자 키로 고른 버튼으로 포커스 이동(기존 결함) |
| 9 `prefix_ids` 부분 치환 | 수용 | 실제 `id` 속성만, href·xlink:href의 `#id`, `url(#id)`, ARIA IDREF 토큰만 바꿈 |
| 10 같은 이름, 다른 스크립트 | 수용 | 게이트 |
| 11 주석 속 금지어, 작은따옴표, 원격 href | 수용 | 주석 제거 후 검사, 따옴표 둘 다, `href/src`·`url()`의 `//` 원격 참조 |
| 12 결정성이 정지점만 봄 | 수용 | 중간 시각도 순방향 재생과 끝에서 점프한 결과를 비교 |
| 13 속성 순서 오탐 | 수용 | 요소별 속성을 이름순으로 정규화해 비교 |
