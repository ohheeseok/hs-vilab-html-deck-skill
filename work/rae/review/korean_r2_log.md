# 한국어 2차 교정: heeseok-korean-anti-slop 1.3.0 (사용자 요청)

Integral 덱에서 사용자가 "AI slop 때문에 이해를 못 하겠다"고 한 뒤 다른 덱에도 같은 기준을 적용했다. 교정표는 `korean_r2.md`(16행).

검사기 후보는 적었다(연결어미 뒤 쉼표 41건은 대부분 정상). 고친 것:
- **21번 정리·토론**: 화살표·기호(→, ≠)로 압축한 항목을 문장으로("② DiT 폭을 토큰 차원 이상으로 하고 … 더하면 … gFID 1.51", "단서: 복원이 좋다고 생성도 좋지는 않고(MAE) …"). 정의 없던 "random 평가"는 대본에서 class-balanced와 함께 정의하고, 화면에는 "클래스를 무작위로 뽑아 평가하면"으로. "Latent 비용"은 "Latent 저장 비용"으로 대상을 밝힘 (L3-3, L1-11)
- **14·16번 reveals**: 명사로 끝나는 나열을 문장으로 (L3-3)
- **5번 제목**: "RAE 위의 복원과 생성, 그리고 바꾸는 곳" → "RAE의 복원·생성 경로와 바꾸는 네 곳"
- **장 번호 오류(사실 수정)**: 0.5.0에서 overview 두 장을 넣은 뒤 참조가 옛 번호로 남아 있었다. 7번 본문·대본과 16번 대본의 "18번" → 19번(인코더 선택), 19번 대본의 "6번" → 7번(세 인코더의 복원). `apply_text_edits.py`가 숫자 변경으로 거부한 4행이라 직접 고쳤다.

남긴 후보: L1-5 2건(실제 대조), L2-1·L2-4·L2-5 각 1–3건(문맥상 기술 서술).
