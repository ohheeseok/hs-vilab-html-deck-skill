# 한국어 편집 처리 기록

편집자: codex(`kref/prompt.md`, 번들 `korean-style.md` + 검사기 후보 + 원 논문). 결과 `korean.md` 112행.

- 화면 문구 51행: 행위자와 대상을 밝히는 방향은 받아들이고, 화면에서 넘칠 만큼 길어진 행 11개는 진행자가 줄여서 적용(`korean_applied.md`의 "진행자 조정"). 숫자 표기가 바뀌어 `apply_text_edits.py`가 거부한 7행 중 토론 두 항목은 손으로 반영.
- 대본 61행: 적용한 뒤, 대본 전체가 20분에 초당 7.8자(약 31분 분량)라 진행자가 슬라이드별로 다시 썼다(초당 4.8자, 이후 검증 반영으로 5.0자). 편집의 방향(누가 무엇을 하는지, 압축 명사구 풀기)은 유지.
- "확인 필요"로 남긴 1건(20번 대본의 병렬 구현 문장)은 "다시 뽑을 때마다 모든 입자의 점수를 기다리는 시간"으로 뜻을 좁혀 해결.
