# 샘플 피드백 반영안 (Claude 종합, codex·agy 1회 검토 반영)

입력: 사용자 피드백 5개(04-feedback-brief.md), codex 검토(04-codex-feedback.md), agy 검토(04-agy-feedback.md).
대비비는 Claude가 sRGB로 다시 계산했다.

## 1. 2·6번 진한 배경 — 채택

- 방식: `statement` 슬라이드에 `data-theme="dark"`. 다크 토큰 블록을 `.slide[data-theme="dark"]`에도 걸어 슬라이드 범위로 적용(두 검토 공통 지적: 지금 토큰은 `:root`에만 걸려 속성만으로는 안 바뀜). `meta.statementTheme: "dark" | "light"`, 기본 dark.
- 바탕: `#12263D`(다크 surface-brand, 남색 계열). 제목 `#F1F5FA` 14.00:1, 본문 `#D5DDE8` 11.19:1, 보조 `#A8B5C8` 7.38:1, 불릿·현재 구간 `#4EB3F0` 6.59:1.
  - 쟁점: agy는 `#0E131B`(17.01:1) 권고. 다크 패널(`#1E2736`, 1.02:1)과 해석 배지(info-bg가 같은 `#12263D`)가 묻힌다는 이유. 아래처럼 패널을 다크 슬라이드에 쓰지 않고 배지를 덮어쓰면 문제가 없어지고, `#0E131B`는 레터박스와 같은 색이라 경계가 사라진다. 사용자가 원한 "진한 배경"의 남색 인상도 `#12263D` 쪽이 강하다. → `#12263D` 채택, 사용자 확인 시 `#0E131B`로 바꾸는 것은 토큰 한 줄.
- 따라 바뀌는 것: 진행 표시줄(미진행 `#263142`, 지난 구간 `#6B7D96`, 현재 `#4EB3F0` — agy: 지금 `--hs-sky-blue-30`은 다크 위에서 현재 구간보다 밝아 위계가 뒤집힘), 흰색 로고, "해석" 배지(바탕 투명 + `#3A7FB8` 테두리 3.58:1 + `#8FC8F5` 글자 8.57:1), 수식은 currentColor라 자동.
- PDF: 화면 그대로(다크 유지, `print-color-adjust: exact`). 배포용 handout은 라이트. (codex는 PDF 라이트 고정 권고 — 발표 PDF가 화면과 달라지면 혼란이라 화면과 같게 둔다.)

## 2. 표지 라인 — 채택, eyebrow는 뺌

- 두 검토 모두 eyebrow 반대(행사명이 오른쪽에 이미 있음, `A · B · C` 메타 줄 금지 규칙).
- 부제 아래 기존 여백에 전체 폭 **2px `--hs-grey-40` `#B9BABB`**(1.94:1) 가로선, 왼쪽 끝에 **120×6px Sky `#048DDB`**(3.60:1) 막대를 겹친다. codex 지적대로 1px `#E4E5E5`는 1024×768에서 0.53px라 사라지므로 2px·grey-40으로 올렸다. Fig. 1 크기는 줄이지 않는다.

## 3. 모션 — 채택, 단 "슬라이드당 자동 연출 1개"

규칙 §8의 "페이지당 한 번"을 "슬라이드당 한 번"으로 읽는다. 두 검토 모두 블록별 3단 순차 등장(stagger)에 반대 → 제거.

| 종류 | 언제 | 값 |
|---|---|---|
| 슬라이드 전환 | 앞으로 한 장 이동 | 들어오는 슬라이드 opacity 0→1 + translateX 4px→0, 180ms `--ease-out`. 뒤로·점프·해시 이동은 즉시 |
| 도착 연출 (슬라이드당 1개) | 첫 순방향 도착 | 막대: 0→값 280ms(값 라벨은 처음부터 표시 — 발표자가 바로 가리킬 수 있게). 표: 강조 행 틴트 180ms. 그림: 없음(전환으로 충분) |
| 반응 모션 | 토글 조작 | `[data-show]` 요소(마스크 테두리·teacher 패널) 180ms 교차 페이드. 버튼 상태·수식·설명은 즉시 |

- 연타: 진행 중 연출을 취소하고 최종 상태로. 전환이 키 입력을 막지 않는다.
- 끄는 곳: `prefers-reduced-motion`, 인쇄, overview, `?motion=0`(QA 캡처는 이 모드).
- 막대 성장은 §8의 "scale-in 금지"(요소 등장 연출)와 달리 값을 그리는 데이터 모션으로 본다.

## 4. 비교 인터랙션 — 유지·강화

- 방법 슬라이드의 대표 인터랙션은 "기존 vs 제안" 상태 토글을 기본 권장으로 SKILL.md에 명시. 게이트(대표 0–1개, 인터랙티브 슬라이드 ≤ max(1, ⌊N×0.2⌋)) 유지.
- 와이프 슬라이더는 v1.1 유지(정렬된 짝 이미지가 드물고 드래그가 클리커 흐름을 끊음).
- **추가(agy 대안)**: 결과 슬라이드의 델타 항목에 포인터·포커스를 두면 차트·표에서 비교한 두 항목(REPA ↔ Self-Flow)에 마커가 120ms로 나타남. 숨은 내용이 없어 인터랙티브 슬라이드 수에 넣지 않고, PDF는 정적.
- codex 지적 반영: 3번 캡션 "마스크 토큰만 s로 더 흐리게"를 "이 예시에서 마스크 9개는 s = 0.8"로 고쳐 예시를 일반 규칙으로 읽지 않게.

## 5. 구역 나누기 — 채택, 두 가지 요소만

- `panel`: radius 6px, 1px 테두리, 그림자 0, 안쪽 여백 기본 32×36px·좁은 열 24×28px(agy: 40–48px은 3번 dual 상태에서 넘침). 흰 바탕 위 `--color-surface-sunken` + `--color-border-subtle`, wash 위 흰색 + `--color-border-subtle`. 슬라이드당 최대 2개, 중첩 금지, 왼쪽 색 띠 금지, 다크 슬라이드에서는 쓰지 않음.
- `divider`: 두 열 사이 세로선 2px. 라이트 `--hs-grey-40`, 다크 `#4A5D78`(2.28:1).
- 샘플 적용:
  - 2·6번: 두 열 사이 세로 `divider` (codex: 두 열이 이미 96px로 갈라져 있어 패널보다 선이 맞음)
  - 3번: 오른쪽 readout(상태명·수식·설명)을 `panel` 하나로
  - 4·5번: 오른쪽 델타 묶음을 `panel` 하나로
- 게이트: 슬라이드당 패널 ≤ 2, 패널 중첩 없음, 덱의 40% 이상은 패널 없음.

## 6. 함께 바꾸는 QA

- `?motion=0`으로 최종 상태 캡처, 1024×768 캡처 추가, 다크 슬라이드 실측 대비, 패널 수·중첩 게이트, 연타(100ms 간격 →) 후 투명 잔상 없음.

## 반영 순서

1. 토큰·엔진: 슬라이드 범위 다크 테마, 진행바·배지·로고 다크 변형
2. 블록: `panel`, `divider`, 표지 라인
3. 모션: 전환·도착 연출·토글 페이드·연타 취소·끄는 조건
4. 3번 캡션 수정, 델타↔비교쌍 하이라이트
5. QA 확장 후 6장 재캡처, 1024×768 점검
