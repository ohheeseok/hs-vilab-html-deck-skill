# 시각 검수 2회차: hs-vilab-html-deck 샘플 6장 (Self-Flow 논문 리뷰)

너는 이 덱의 **시각 검수자**다. 코드는 고치지 말고, 캡처 이미지를 직접 보고 판단한 결과만 써라.
덱은 1920×1080 무대를 브라우저 창에 맞춰 축소·확대하는 HTML 발표자료다(PPT 대용). 발표자는 연구실 교수이고, 연구실 세미나 프로젝터(1024×768일 수 있음)와 노트북 화면에서 쓴다.

1회차 검수(13건)를 받아 수정했다. 이번 회차의 목적은 두 가지다.
1. **1회차 수정이 제대로 되었는지** 확인하고, 수정 때문에 **새로 생긴 문제**를 찾는다.
2. 1회차에서 놓친 문제가 있으면 찾는다.

## 이 폴더에 있는 것 (읽기 전용)
- `shots/1920/`, `shots/1024/` : 수정 후 캡처. s01 표지, s02 요약(다크), s03-vanilla·s03-dual(같은 슬라이드의 토글 두 상태), s04 T2I 결과 막대, s05 ImageNet 표, s06 정리와 토론(다크). 1024는 1024×768 창(위아래 레터박스)이고, 프로젝터 가독성은 이걸로 판단하라.
- `round1/` : 1회차 1920 캡처(수정 전), 1회차 지적 원문 `06-agy-visual-r1.md`, 건별 처리 `07-claude-visual-triage.md`. **전후 비교에 써라.**
- `rules/SKILL.md`, `rules/design-system.md` : 디자인 원천 규칙. `tokens.css`, `deck.css`, `deck.json`, `PLAN.md`.
- 캡처는 모션이 끝난 최종 상태(`?motion=0`)다.
